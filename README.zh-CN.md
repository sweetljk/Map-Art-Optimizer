# Map Art Optimizer 0.1.0

将 Xaero 世界地图中已经探索的地表图像，显示在原版物品展示框里的地图上。仅客户端运行，不需要服务器安装。

## 适配版本

- Minecraft Java 26.1.2
- Fabric Loader 0.19.3 或更高版本
- Fabric API 0.155.3+26.1.2
- **Xaero's World Map 1.41.3**（必须为这个版本）
- Java 25

Xaero 世界地图需另行安装。本项目不包含 Xaero 或 Minecraft 的程序文件。

## 安装和使用

1. 将 `map-art-optimizer-0.1.0.jar` 放进该游戏实例的 `mods` 文件夹，重启游戏。
2. 进入服务器，按 M 打开 Xaero 世界地图，确认选中了正确的世界/维度/地图实例。
3. 对准一张装在展示框里的地图，输入以下任意一种绑定命令：

```text
/xmapframe bind <地图中心X> <地图中心Z>
/xmapframe corner <地图西北角X> <地图西北角Z>
```

缩放等级从原版地图读取。例如一张覆盖 512×512 方块、中心为 `(192,192)` 的地图，西北角为 `(-64,-64)`，可以输入：

```text
/xmapframe bind 192 192
```

也可以先把地图拿在手中，**站到这张地图实际描绘的区域内**，输入：

```text
/xmapframe here
```

`here` 根据玩家所在的原版地图网格推算边界。如果玩家不在这张地图描绘的区域内，会绑定到错误位置；此时重新使用 `bind` 或 `corner` 即可覆盖绑定。绑定中心时输入的是地图中心，不是展示框位置。

4. 看向展示框，等待高清瓦片逐步加载。第一次读取较大的历史地图需要更长时间。没有 Xaero 地形数据的部分保留原版底图。
5. 输入 `/xmapframe status` 查看当前目标地图的高清覆盖比例和诊断信息。

其他命令：

```text
/xmapframe help       显示帮助
/xmapframe unbind     取消当前目标/手持地图的绑定
/xmapframe refresh    重新读取高清瓦片
/xmapframe off        暂时关闭覆盖
/xmapframe on         重新开启覆盖
```

同一地图编号在这个世界中的所有展示框使用相同绑定。多张不同编号的地图可分别绑定相邻范围来拼接地图墙。绑定只保存在该实例的 `config/xaero-map-frames.json` 中，使用 Xaero 的世界、维度和多世界地图实例隔离。改名后保留此配置文件名，以继续读取已有绑定；指令仍为 `/xmapframe`。

## 当前行为和边界

- 高清地形为 **一方块一个像素**：0级地图128×128，1级256×256，2级512×512，3级1024×1024，4级2048×2048。0级地图主要改善色彩；它已经达到一方块一像素，不会凭空多出方块内部的纹理细节。
- 仅替换展示框底图，保留原版旋转、发光效果、图标和标记文字。手持地图继续显示原版内容。
- 当前版本没有导入 Xaero 路径点、地名或字体；原版标记文字也没有重新设计。
- 只读取当前 Xaero 地表地图。切换到其他维度或其他地图实例时，需要该实例自己的绑定。
- 高清区域取决于本机 Xaero 的探索数据。其他玩家探索过、但没有同步给你区块的区域，不会自动变高清。服务器不会收到高清像素。
- 采用白天地表色彩；Xaero 的夜间亮度、屏幕滤镜、界面叠加和自定义着色器效果不会全部复现。
- 高清覆盖会随本地 Xaero 数据变化，包括原版已锁定的地图。本版本不保存锁定地图的历史快照。
- 采用有界 CPU 瓦片缓存和高清纹理预算。大地图墙可能逐步降回原版底图，随后重新加载；此版本未针对数百张大型地图同时显示优化。
- 这是首个原型版本。已完成的编译、结构及逻辑检查记录见交付说明；未声称已在图形客户端或你的服务器中完成画面实测。

## 从源码构建

正常构建使用 Gradle 9.6.0、JDK 25 和 Fabric Loom。将另行获取的 Xaero 1.41.3 JAR 放入 `libs/xaeroworldmap-fabric-26.1.2-1.41.3.jar`，或用 `-PxaeroJar=<绝对路径>` 指定。

此工作区也提供 `build-local.ps1`，可以复用已有的相同版本 Minecraft/Fabric 开发缓存进行离线构建。Minecraft 26.1.2 不再混淆，所有注入使用其官方类名，离线分支无需重映射。

```powershell
.\build-local.ps1 `
  -DependencyCache 'E:\Gradle\.gradle' `
  -JavaHome 'E:\graalvm-jdk-25_windows-x64_bin\graalvm-jdk-25.0.4+7.1' `
  -XaeroJar '<你自己的 Xaero World Map 1.41.3 JAR 路径>'
```

构建产物位于 `build/libs`。构建脚本只读取既有依赖缓存，构建临时文件写入项目自己的 `.local-build` 和 `build` 文件夹。

`verify-local.ps1 -JavaHome <JDK25目录> -XaeroJar <Xaero1.41.3文件>` 可在离线构建后运行绑定持久化、失败保护和真实 Xaero 像素/历史缓存格式测试，不会打开游戏。该电脑的受限执行环境中，JDK 有时会在编译完成后关闭 ZipFS 时输出 AccessDeniedException；构建通过外部 javac 运行，最终 JAR 另经结构检查和实际类加载验证。
